Privacy policy

Last updated: October 29, 2026.

This policy covers a private Google OAuth client used by a single person to run the open-source rclone tool against their own Google Drive. See the home page.

What the app accesses

With the owner's consent, the client reads and writes files in the owner's own Google Drive, and reads Google Docs the owner has been given access to. It does this only to upload finished files and to read one shared document.

What is stored, and where

The access and refresh tokens Google issues are saved in rclone's configuration file on the owner's own computer. Nothing is sent to or stored on any server run by the owner of this client, and there is no website, database or analytics behind it.

What is shared

Nothing. No data from Google APIs is sold, shared, transferred to third parties, used for advertising, or read by any person other than the owner.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
